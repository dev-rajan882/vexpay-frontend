Section 1 · Core System Design

How VEX PAY Works (Human & AI Overview)

Zero-Fee UPI Automation

VEX PAY ek self-hosted real-time UPI payment gateway hai jo incoming Paytm Business email alerts ko Gmail OAuth API ke through padhta hai aur Dynamic Paise Slotting (+0.01 se +0.30) ke zariye har order ko 100% accuracy ke saath auto-verify karta hai.

STEP 1 · CREATE ORDER
Dynamic Paise Slot

Agar user ₹100 add karta hai, gateway free slot (jaise ₹100.01) lock karta hai aur UPI QR + Intent link banata hai.

STEP 2 · USER PAYS
QR Scan or UPI App

User GPay, PhonePe, ya Paytm se exact ₹100.01 pay karta hai (UPI Intent me amount pre-filled rehta hai).

STEP 3 · AUTO-SYNC
Live Gmail Verification

Jab aapka app /api/order-status poll karta hai, backend automatically Gmail check karke UTR match karta hai.

STEP 4 · INSTANT CREDIT
Polling + Webhook

Order status SUCCESS ho jata hai aur aapke webhook URL parUTR ke saath POST event bhej diya jata hai.

Parameter / Rule Value Developer / AI Instruction
Dynamic Slot Range +₹0.01 to +₹0.30 (30 slots/amount) User ko hamesha order.payableAmount (e.g. 100.01) dikhayein, par wallet mein base amount (100) credit karein.
Order Validity Window 5 Minutes (300,000 ms) Checkout screen par expiresAtMs tak 5 minute ka countdown timer dikhayein.
Slot Cooldown Gap 5 Minutes after Verify/Expire Ek slot use hone ke 5 minute baad hi dobara kisi naye order ko allot hota hai.
Recommended Polling Rate Every 3 to 4 Seconds GET /api/order-status?orderId=... call karne se Vercel par auto-Gmail sync apne aap trigger hota hai.

        Section 8 · Mandatory Checklist
        
5 Golden Rules for Developers & AI Assistants

        
    
          
  • Hamesha Full HTTPS URL use karein: https://vexpay-seven.vercel.app (kabhi bhi bina https:// ke URL pass na karein).
    • 
          
  • Exact Payable Amount Dikhayein: Customer ko QR ke upar bold अक्षरों mein order.payableAmount (jaise ₹100.01) dikhayein taaki wo exact paise transfer kare.
    • 
          
  • Wallet Mein Base Amount Credit Karein: Jab order SUCCESS ho, user ke game/app wallet mein requested amount (₹100) add karein, extra slot paise (.01) sirf matching ke liye hain.
    • 
          
  • UTR / Order ID Idempotency Rakhein: Ek orderId ya utr par sirf ek baar wallet balance badhayein (agar polling aur webhook dono aayein toh double credit na ho).
    • 
          
  • Polling Chalu Rakhein: Jab user payment screen par ho, har 3–4 second mein GET /api/order-status?orderId=... call karein — isse Vercel backend automatically Gmail check karke order ko SUCCESS mark kar deta hai.
